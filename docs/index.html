Porous Fe-Cr Oxidation Predictor

Physics-based prediction for porous sintered Fe-Cr steels (Fe20Cr, Fe22Cr, Fe27Cr). No login, runs in browser.

Results

Sintered porosity = pore network of sintered metal (~30%). Oxide-layer porosity = voids in oxide scale. Mass gain mg/cm², thickness µm. Parabolic law: dm = 1000·sqrt(kp·3600·t), kp from Arrhenius Ea≈2.7 eV, kp(22Cr,700°C)=4.5e-15 g²/cm⁴/s.
