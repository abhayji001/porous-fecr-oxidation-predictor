Porous Fe-Cr Oxidation Predictor

Physics-based prediction for porous sintered Fe-Cr steels (Fe20Cr, Fe22Cr, Fe27Cr, ~30% sintered porosity). Parabolic law + Arrhenius. Runs fully in browser.

Data & Model

Model: dm = 1000*sqrt(kp*3600*t), kp(Fe22Cr,700°C)=4.5e-15 g²/cm⁴/s, Ea≈2.7 eV [Koszelow et al. Corros. Sci. 189:109589 (2021), Metall. Mater. Trans. A 54:2244 (2023), CC-BY-4.0].
Code: Apache-2.0. This is a prediction, not a measurement. Outside 20-27%Cr, 600-900°C or >6000h = extrapolation.
