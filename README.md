# Porous Fe-Cr Oxidation Predictor

Live site: https://abhayji001.github.io/porous-fecr-oxidation-predictor/

Physics-based prediction for porous sintered Fe-Cr steels (Fe20Cr, Fe22Cr, Fe27Cr).
Parabolic law dm = 1000*sqrt(kp*3600*t), Ea ~2.7 eV, kp(22Cr,700C)=4.5e-15.

Runs fully in browser (docs/index.html). Code Apache-2.0.
Data from Koszelow et al. 2021, 2023 (CC-BY-4.0).
